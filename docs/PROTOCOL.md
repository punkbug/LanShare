# LanShare 전송 프로토콜 초안

macOS, Android, iOS, Windows 앱이 사용하는 개발용 v1 프로토콜입니다. 단일 파일 LAN 전송에 사용하며 안전한 공개 규격으로 확정된 상태는 아닙니다.

## 발견

- Bonjour 서비스: `_lanshare._tcp`
- 각 앱 인스턴스는 TCP 수신기를 열고 Bonjour에 게시합니다.
- 서비스 인스턴스 이름은 `LanShare-####` 형식이며 `####`는 앱이 실행 중 표시하는 4자리 코드입니다. 사용자는 상대 앱에 표시된 코드를 입력하고, 앱은 mDNS로 발견한 일치 항목의 LAN 주소와 포트로 직접 TCP 연결합니다.
- Windows는 IPv4 mDNS를 직접 송수신하므로 Windows 방화벽에서 개인 네트워크 검색/수신을 허용해야 할 수 있습니다.
- 앱 간 전송은 웹페이지, 인터넷 시그널링, 클라우드 저장소를 사용하지 않습니다. 두 앱은 같은 로컬 네트워크에서 mDNS 검색과 TCP 연결이 가능해야 합니다.

## 요청

TCP 연결 후 UTF-8 JSON 한 줄을 보냅니다. 버전 1 필드는 다음과 같습니다.

```json
{"version":1,"sender":"Mac 이름","fileName":"photo.jpg","size":12345}
```

수신 앱은 요청을 사용자에게 보여주고 승인 또는 거절합니다. 승인 응답은 `ACCEPT\n`, 거절 응답은 `REJECT\n`입니다. 승인 뒤 송신자는 정확히 `size` 바이트를 스트리밍합니다. 수신자는 크기를 확인한 뒤 파일을 저장합니다.

모든 클라이언트는 소문자 필드명(`version`, `sender`, `fileName`, `size`)을 사용합니다. 줄바꿈 전 헤더는 최대 4096바이트이며, `size`는 0에서 100,000,000,000바이트 사이입니다. 파일명은 단일 경로 구성 요소여야 하며 수신자는 경로 구분자, 제어 문자, 크기 제한 위반을 거부합니다. 저장 위치는 플랫폼별로 다릅니다.

## 미해결 보안 요구사항

이 초안은 암호화, 상호 인증, 무결성 해시를 아직 구현하지 않습니다. 수신 승인만으로 LAN 내 도청이나 능동 공격을 막을 수 없습니다. 이 빌드는 신뢰하는 개인 네트워크에서만 개발용으로 사용해야 합니다. 플랫폼 간 공개 테스트 전에 표준 TLS 기반 호스트 인증/키 교환, 세션 인증, 파일 해시 검증, 취소/타임아웃/재시도 규칙을 설계하고 보안 검토를 거쳐야 합니다. 현재 초안은 배포 규격으로 사용하지 않습니다.
