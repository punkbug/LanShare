Key Features

왜 LanShare여야 할까요?

불필요한 클라우드 업로드 없이, 내 공유기의 물리적 최대 대역폭으로 기기끼리 직접 전송합니다.

⚡

초고속 LAN 직결 (P2P)

인터넷 외부망을 경유하지 않고 Wi-Fi 또는 유선 랜(1Gbps/10Gbps) 대역폭을 그대로 활용하여 기가바이트급 영상이나 파일도 순식간에 복사됩니다.

🔒

제로 클라우드 프라이버시

어떤 파일 데이터나 비밀 토큰도 외부 서버에 저장되지 않습니다. 사내 기밀 보고서, 개인 사진, 영상도 외부 유출 우려 없이 안전합니다.

🚫

회원가입 & 로그인 ZERO

이메일 인증, 비밀번호 기억, 계정 생성이 전혀 필요 없습니다. 앱을 켜면 즉시 사용 준비가 완료됩니다.

📡

자동 검색 & 수동 IP 지원

Bonjour/mDNS 프로토콜로 같은 네트워크 기기를 자동으로 찾아주며, 학교나 공공 Wi-Fi처럼 브로드캐스트가 차단된 환경에서도 IP 직접 입력으로 전송할 수 있습니다.

🛡️

안전한 사전 수신 승인

수신자에게 보낸 사람, 파일 이름, 전체 용량을 먼저 확인받고 [수락/거절]을 거치므로 악성 파일이나 원치 않는 파일의 자동 수신을 철저히 차단합니다.

📊

실시간 진행률 & 속도 모니터링

현재 전송 속도(MB/s), 남은 예상 시간, 전송 진행률(%)이 양쪽 화면에서 실시간으로 동기화되어 전송 상황을 한눈에 파악할 수 있습니다.

How It Works

단 3단계로 끝나는 전송

복잡한 페어링이나 코드 입력 없이 가장 직관적인 흐름을 제공합니다.

1

같은 네트워크 연결

보내는 기기와 받는 기기를 동일한 공유기(Wi-Fi 또는 유선 LAN)에 연결하고 LanShare 앱을 실행합니다.

2

파일 선택 & 대상 선택

전송할 파일을 드래그하여 앱에 올리고, 자동으로 검색된 주변 기기 목록에서 대상 기기를 터치합니다.

3

수신 승인 즉시 전송 완료

받는 기기 화면에 뜨는 알림창에서 [수락]을 누르면 즉시 초고속으로 전송되어 다운로드 폴더에 안전하게 저장됩니다.

Supported Platforms

모든 운영체제에서 만나는 LanShare

동일한 v1 네트워크 전송 프로토콜을 구현하여 이기종 기기 간 원활한 파일 교환이 가능합니다.

macOS 네이티브 앱

Swift & SwiftUI로 작성된 고성능 네이티브 클라이언트 · Apple Silicon 및 Intel Mac 완벽 지원 (macOS 13+)

💿 LanShare 설치 (.dmg) 📦 앱 번들 (.zip)
터미널에서 즉시 실행 또는 빌드하기:
# 저장소 루트에서 즉시 실행 swift run # 또는 독립 실행형 .app 번들 빌드 bash scripts/build-app.sh open dist/LanShare.app

💡 최초 실행 시 로컬 네트워크 검색 권한을 허용해주세요. 수신된 파일은 기본적으로 '다운로드' 폴더에 저장됩니다.

Android 앱

Kotlin & Jetpack Compose 기반 모던 UI · Android 8.0 (API 26) 이상 완벽 호환

⬇️ LanShare APK 다운로드 (.apk)
📲 APK 설치 안내

1. 스마트폰 브라우저에서 상단 [LanShare APK 다운로드] 버튼을 누릅니다.
2. 다운로드 완료 후 파일을 탭하고 '출처를 알 수 없는 앱 설치 허용'을 선택하면 즉시 설치됩니다.

개발자용 소스코드 빌드:
cd Android ./gradlew assembleDebug # 연결된 스마트폰에 즉시 설치 ./gradlew installDebug

Windows 데스크톱 앱

.NET 8 WPF 기반 · Windows 10 / 11 64-bit 지원 (mDNS 자동 탐색 및 고속 전송)

⬇️ Windows 간편 패키지 다운로드 (.zip)
⚡ Windows 1-클릭 실행 및 .exe 빌드

1. [Windows 간편 패키지 다운로드]를 받아 압축을 풉니다.
2. Install-And-Run.bat을 더블 클릭하면 .NET 환경 확인 및 단일 실행 파일(LanShare.exe)을 자동 생성하여 즉시 실행합니다.
3. Windows Defender 방화벽 창이 뜨면 [개인 네트워크 허용]을 클릭하세요.

수동 터미널 빌드:
cd Windows/LanShare.Windows dotnet build -c Release dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true

iOS / iPadOS 앱

SwiftUI 기반 클라이언트 · iOS 16 이상 지원 (iPhone & iPad)

⬇️ LanShare.ipa 다운로드 ✈️ TestFlight 출시 알림
📲 Sideloadly로 iPhone에 3분 만에 설치하기
  1. PC나 Mac에서 무료 사이드로딩 도구인 Sideloadly를 설치하고 실행합니다.
  2. 아이폰을 케이블로 연결한 뒤, 상단에서 다운로드한 LanShare-iOS.ipa 파일을 Sideloadly 창에 끌어다 놓습니다.
  3. 자신의 무료 Apple ID(iCloud 계정)를 입력하고 Start를 누르면 아이폰에 앱이 설치됩니다.
  4. 아이폰의 [설정] → [일반] → [VPN 및 기기 관리]에서 본인 계정을 '신뢰' 선택하면 바로 실행됩니다!
💡 TrollStore 기기 사용자는 사파리에서 .ipa를 다운받아 바로 원클릭 영구 설치하실 수 있습니다.
Xcode 직접 빌드 (Mac 사용자):
open iOS/LanShareIOS.xcodeproj

💡 iOS 운영체제 정책상 백그라운드 소켓 수신이 제한되므로, 파일 전송 중에는 앱을 화면 전면에 열어두어야 합니다.

전송 경로 기기간 1:1 직결 (LAN) 인터넷 서버 업로드 후 다운로드 메신저 중앙 서버 경유

Frequently Asked Questions

자주 묻는 질문

LanShare 사용과 네트워크 연결에 관한 궁금증을 해결해드립니다.

인터넷 연결이 없는 오프라인 환경에서도 작동하나요? ▼
네! 외부 인터넷망 연결이 차단된 폐쇄망 공유기나 핫스팟 환경에서도 같은 무선/유선 네트워크에 연결되어 있다면 문제없이 고속 전송이 가능합니다.
기기 목록에 상대방 기기가 자동으로 뜨지 않아요. ▼
일부 공공 Wi-Fi나 기업 네트워크에서는 보안을 위해 'AP 격리(Client Isolation)'가 활성화되어 mDNS 브로드캐스트가 차단될 수 있습니다. 이 경우 앱의 '수동 IP 연결' 기능을 이용해 상대 기기의 IP 주소를 직접 입력하여 즉시 연결할 수 있습니다.
전송 프로토콜 규격은 어디서 확인할 수 있나요? ▼
저장소의 docs/PROTOCOL.md 파일에 mDNS 서비스 레코드(_lanshare._tcp), TCP 핸드셰이크(발견·승인·헤더 규약) 및 바이너리 스트리밍 포맷이 투명하게 명세되어 있습니다. 누구나 자신만의 클라이언트를 구현할 수 있습니다.
받은 파일은 어디에 저장되나요? ▼
macOS와 Windows에서는 사용자의 '다운로드(Downloads)' 폴더에 자동으로 안전하게 저장되며, 수신자가 승인을 마친 후에만 기록을 시작합니다.
전송 중 파일이 암호화되나요? ▼
현재 구현된 v1 개발 규약은 로컬 사설망 직접 전송에 초점을 맞춘 초안 프로토콜입니다. 따라서 신뢰할 수 있는 개인 가정이나 사내 내부망에서 사용하시길 권장하며, 추후 릴리스에서 TLS 세션 암호화와 기기 간 지문 검증이 추가될 예정입니다.
